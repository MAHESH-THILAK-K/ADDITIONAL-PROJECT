# PICO_Z

**PICO_Z** is a compact Raspberry Pi Pico-style development board designed as a smaller version with exposed GPIO pins for easy prototyping and embedded development.

## Features

- Compact Pico-compatible form factor
- Exposed GPIO pins for quick access
- USB Type-C connector for power and programming
- SWD interface for debugging and flashing
- SWO pin exposed for advanced debugging and trace
- Suitable for breadboard, robotics, IoT, and embedded projects

## Purpose

This board is designed to provide a smaller and cleaner Pico-style hardware platform while keeping important development and debugging pins accessible.

## Hardware Highlights

| Feature | Description |
|---|---|
| MCU | RP2040 / Pico-compatible controller |
| USB | USB Type-C |
| Debug | SWD and SWO exposed |
| GPIO | Exposed pins for external connections |
| Use Case | Prototyping, robotics, IoT, embedded systems |
